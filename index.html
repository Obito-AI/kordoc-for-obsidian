Obsidian Desktop kordoc bridge HWP/HWPX/PDF → Markdown

kordoc for Obsidian

kordoc for Obsidian은 Obsidian Desktop에서 kordoc CLI를 호출해 HWP/HWPX/PDF/Office/이미지 문서를 Markdown, chunks JSON, 마스킹본, HWPX 생성물로 저장하는 브릿지 플러그인입니다.

GitHub 저장소 · v0.1.0 릴리스

핵심 요약

문서 → Markdown

HWP, HWPX, PDF, DOCX, XLS/XLSX, 이미지 파일을 Obsidian 노트로 변환합니다.

chunks JSON

검색, RAG, AI 분석에 활용할 수 있는 구조 청크 JSON을 생성합니다.

Markdown → HWPX

현재 Markdown 노트를 kordoc generate로 HWPX 파일로 변환합니다.

개인정보 마스킹

redacted 파일과 검토필요 리뷰 노트를 함께 생성합니다.

지원 입력 파일

.hwp .hwpx .hml .pdf .xls .xlsx .docx .png .jpg .jpeg .webp

설치 방법: BRAT

  1. Obsidian에서 커뮤니티 플러그인 BRAT을 설치합니다.
  2. BRAT 설정에서 Add Beta Plugin을 선택합니다.
  3. 아래 저장소 URL을 입력합니다.
https://github.com/Obito-AI/kordoc-for-obsidian
  1. Community Plugins에서 kordoc for Obsidian을 활성화합니다.

요구사항

  • Obsidian Desktop, 모바일 미지원
  • Node.js와 npm
  • 기본 실행 방식: npx -y kordoc

반복 사용이 많으면 전역 설치도 가능합니다.

npm install -g kordoc
kordoc --version

Obsidian에서 보이는 명령

명령기능
Kordoc: Parse current file to Markdown현재 문서를 Markdown으로 변환
Kordoc: Parse current file to chunks JSON현재 문서를 chunks JSON으로 변환
Kordoc: Generate HWPX from current Markdown note현재 Markdown 노트를 HWPX로 생성
Kordoc: Create redacted copy of current file마스킹본과 검토 노트 생성

안전 주의

원본 파일은 덮어쓰지 않습니다. 생성물은 별도 폴더에 저장됩니다.

개인정보 마스킹은 자동 검출 보조 기능입니다. 공개·전송 전 반드시 사람이 검토해야 합니다.
